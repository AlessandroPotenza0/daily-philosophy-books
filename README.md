# Daily Philosophy books

Public-domain books for the Daily Philosophy app's reader. The app downloads
`books/<id>.json` from this repository the first time a book is opened.

The texts come from [Standard Ebooks](https://standardebooks.org), whose editions
are dedicated to the public domain (CC0). Every translation used here is in the
public domain worldwide. The files are generated by `tool/convert_books.py` in the
app's repository; edit them there, not here.
